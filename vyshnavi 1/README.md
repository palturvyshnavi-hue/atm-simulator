# ATM Simulator in Python

A simple command-line ATM Simulator developed using Python.

This project demonstrates basic Python programming concepts such as:

- Classes and Objects
- Functions
- Conditional Statements
- Loops
- Exception Handling
- User Input
- Unit Testing
- Object-Oriented Programming

## Features

The ATM Simulator provides the following features:

1. PIN authentication
2. Check account balance
3. Deposit money
4. Withdraw money
5. Insufficient balance checking
6. Invalid input handling
7. Maximum login attempts
8. Account locking after failed attempts
9. Unit testing using Python unittest
